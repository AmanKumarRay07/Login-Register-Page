# Login and Register Page

## About the Project
This project is a simple login and registration page created using HTML and CSS. It is designed to provide a basic user interface for login and registration.

## Features
- Login page interface
- Registration form interface
- Simple and user-friendly layout

## Technologies Used
- HTML
- CSS (if used in the project)

## Project Files
- `loging.html` — Login page
- `form2.html` — Registration form

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `loging.html` in your web browser.
4. Open `form2.html` to view the registration form.
